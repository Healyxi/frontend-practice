浙江之心
水墨金华

金华位于浙江省中部，是一座拥有两千多年历史的文化名城。 这里山清水秀、人杰地灵，自古便有“小邹鲁”的美称， 是婺州文化的发源地，也是著名的旅游胜地。

金华美食

金华是座小城，却有无数美食让在异乡的游子魂牵梦绕。

金华火腿

中国三大名腿之一，皮薄肉厚、香气浓郁，是金华最响亮的名片。

百年名产

金华酥饼

层层酥皮包裹干菜与肥膘，香酥可口，是传承千年的传统点心。

江南点心

永康肉麦饼

一口下去，是梅干菜的咸香混合着肉香，多汁又美味。

兰溪牛肉面

名胜古迹

被誉为“天下第一洞”的溶洞奇观，洞中有洞、洞下有洞，夏日清凉宜人，是金华最负盛名的避暑胜地。
